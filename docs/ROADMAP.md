# Kindle Dashboard 卡片化路线图

## 已确定的产品方向

看板采用“固定状态区 + 双侧卡片槽”的结构：

- 左上角时间、日期、农历和当前天气是固定状态区，不参与卡片轮换；时间仍按分钟局部刷新，天气按数据源更新。
- 左下区域变成左侧卡片槽，左右横滑切换不同页面。
- 右侧区域变成右侧卡片槽，月历、当天日程、周视图和其他大卡片可以横滑切换。
- 卡片只刷新自己的区域，不因切换或同步而整屏刷新。
- 先支持手动横滑；自动轮播作为可配置能力，默认关闭，避免墨水屏频繁刷新。

## 卡片候选

### 左侧卡片

1. 今日待办与日程：当前主工作卡片，支持纵向分页和点击查看详情。
2. 倒计时：主目标大号显示，辅助目标分行显示；目标从日程条目产生。
3. 未来 5/7 天天气：每日天气、温度范围、降水和风力摘要。
4. 今日要闻：Agent 聚合后的短标题和摘要，支持翻页。
5. Agent 每日简报：天气、日程、待办、重点提醒的合并摘要。
6. 英语学习：每日单词、音标、释义和例句，内容由 Agent 或本地词库提供。
7. 每日卦象：Agent 生成的卦象、简释和建议；标注为娱乐/民俗内容，不作为决策依据。
8. 图片/名言：每日图片或黑白适配的短句卡片，适合低频轮换。
9. 星座运势：根据本地保存的星座显示每日简短运势，标注为娱乐内容。
10. 每日语录：一句短句、出处和可选的 Agent 解读。
11. 每日一题：法考题、英语题或通用知识题，点击后显示答案和解析。
12. 随机任务：喝水、深蹲、拉伸、整理桌面等短任务，完成后点击打卡。
13. 番茄钟：25/5、50/10 等预设，支持开始、暂停、完成和短休息。
14. 电子宠物：Agent 生成外观和性格，本地维护喂食、互动、心情和成长状态。

### 右侧卡片

1. 月历 + 当天日程：保留当前月历选择能力，默认下半部分显示当天日程。
2. 今日完整日程：放大显示当天事件和待办，支持点击日程设置倒计时。
3. 未来一周：独立卡片显示未来 7 天日程，不再和月历卡片强绑定。
4. 详细天气：未来 5/7 天列表或天气趋势。
5. Agent 信息流：新闻、简报、卦象、英语等内容的宽版展示。
6. 时钟卡片：翻页钟或模拟指针时钟，作为可选装饰卡片。
7. 今日习惯：显示随机任务完成数、番茄钟数量和连续打卡天数。
8. 电子宠物：宽版展示宠物状态、简短对话和互动按钮。

## 交互约定

- 左右滑动：切换当前卡片槽的页面。
- 上下滑动：只在当前卡片内部翻页，例如日程列表或新闻摘要。
- 月历点击：切换选中日期，并刷新右侧当天日程；不直接创建倒计时。
- 日程点击：显示日程操作菜单，可将该日程日期和标题设为主倒计时或新增目标。
- 顶部状态区点击：只处理设置、亮度、状态等固定功能，不参与卡片分页。
- 左右两侧的页面索引、启用卡片和自动轮播间隔放入本地布局配置，后续可在设置中调整。

## 数据分层

### 设备本地

- 时间、日期、农历展示和倒计时天数计算。
- 当前卡片页索引、布局顺序和分页位置。
- 最近一次有效快照和 Agent 卡片缓存。

### Hub/同步层

- Apple 日历、提醒事项和天气继续使用现有同步链路。
- 新增统一的只读卡片数据，例如 `cards.news`、`cards.briefing`、`cards.english`、`cards.divination`、`cards.photo`。
- 每种来源独立失败和缓存，某个 Agent 卡片失败不影响日程卡片。

### Agent 层

- 负责生成新闻摘要、每日简报、英语内容、卦象和图片元数据。
- Agent 只写入 Hub 的卡片数据，不直接控制 Kindle UI。
- 卡片内容带有 `id`、`kind`、`title`、`body`、`generated_at`、`expires_at` 和可选图片引用。
- 星座、语录和每日一题可以由 Agent 生成，也可以由本地内容池离线兜底。
- Agent 不直接下发可执行命令；随机任务只下发任务文本、预计时长和完成规则。

### 本地互动层

- 随机任务、习惯打卡和番茄钟状态保存在 Kindle 本地，断网仍可使用。
- 每次打卡写入本地事件日志，后续可以选择是否同步给 Hub；默认不上传隐私数据。
- 番茄钟只刷新当前卡片区域，计时期间不做整屏刷新；设备休眠或离开看板时记录暂停状态。
- 电子宠物的饥饿、精力、心情、亲密度、成长阶段和互动记录保存在 Kindle 本地。
- 宠物不因用户忙碌而死亡、不制造强制惩罚；状态只温和地变化，并允许一键恢复照顾。
- 喂食、玩耍、休息、清洁和完成任务都使用明确按钮，操作后只刷新宠物卡片。

## 电子宠物设计

### 初次生成

- Agent 生成宠物名称、物种/幻想形象、性格、欢迎语和黑白屏可用的头像描述。
- 生成结果落地为本地 `pet.json`，之后日常状态变化不需要再次请求 Agent。
- Agent 可以定期生成新的台词、纪念日或装扮，但不能覆盖用户已有的宠物身份。

### 日常状态

- 饥饿：喂食后恢复，随时间缓慢下降。
- 精力：玩耍消耗，休息恢复。
- 心情：受互动、完成任务和连续陪伴影响。
- 亲密度/成长：来自长期照顾和看板使用，不设置突然死亡或不可逆惩罚。
- 今日状态：显示一句短对话和下一步建议，例如“陪我走五分钟吧”。

### 可扩展功能

- 喂食、玩耍、清洁、睡觉、换装和拍照纪念。
- 宠物作为 Agent 简报的陪伴入口：提醒喝水、鼓励完成番茄钟、提示今日一题。
- 宠物生日、成长阶段、连续照顾天数和成就徽章。
- 随机任务可以由宠物提出，但任务必须可跳过、可关闭，并受免打扰时段限制。

### 墨水屏约束

- 首版使用低灰度头像、表情和少量文字，不依赖动画。
- 动作采用静态状态切换或 2～3 帧低频变化，不做连续动画。
- 宠物卡片独立局部刷新，避免影响时间、日程和月历区域。

## 分阶段实现

### Phase 0：卡片壳层

- 固定左上状态区。
- 左右两个卡片槽和横滑分页状态。
- 卡片级局部刷新和页面缓存。
- 暂不增加新闻、卦象等新数据源。

### Phase 1：日程与倒计时重排

- 左侧拆出“今日安排”和“倒计时”两个卡片。
- 右侧月历卡片默认显示当天日程。
- 未来一周单独成为右侧卡片。
- 保留日程点击设置倒计时的逻辑。

### Phase 2：天气和信息卡片

- 增加未来 5/7 天天气卡片。
- 增加 Agent 新闻/每日简报卡片的数据协议和缓存。
- 增加卡片过期时间、空数据占位和失败回退。

### Phase 3：Agent 内容

- 英语单词卡片。
- 每日卦象卡片。
- 图片/名言卡片，优先使用黑白安全的图片或文字降级。

### Phase 3.5：趣味和互动功能

- 星座运势、每日语录、每日一题。
- 随机任务卡：任务池、冷却时间、完成按钮和每日完成统计。
- 番茄钟卡：预设时长、开始/暂停/完成、短休息和局部计时刷新。
- 今日习惯卡：汇总随机任务与番茄钟，不引入复杂账号体系。

### Phase 3.6：电子宠物

- 本地宠物状态模型和 `pet.json` 持久化。
- 宠物卡片、喂食/玩耍/休息按钮和低频状态更新。
- Agent 初始生成宠物身份，以及可选的每日台词。
- 与随机任务、番茄钟和每日简报建立弱关联，不让宠物阻塞主要信息显示。

### Phase 4：个性化与自动轮播

- 设置卡片启用/禁用和排序。
- 设置左右槽默认页。
- 设置自动轮播间隔、夜间暂停和低电量暂停。
- 增加卡片版本和第三方数据源说明，方便开源发布。

## 当前下一步

先不改 V13 的视觉定稿，优先完成 Phase 0 的卡片壳层和 Phase 1 的日程/倒计时重排。新功能清单继续收集后，再确定卡片顺序、刷新策略和数据协议。
